# Fina-Auto Pro

App para oficinas e mecânicos independentes.

- **Package Android:** `com.finaauto.pro`
- **Tipo Firestore:** `users.tipo = profissional`
- **Subtipo:** `oficina` ou `mecanico` (cria doc em `oficinas` ou `mecanicos`)

```bash
flutter pub get
dart run flutterfire_cli:flutterfire configure
flutter run
```
